# FLASHIN v29 — admin, import/export, preflight

## Added

### Admin frontend

Folder: `admin/`

A separate Vite React admin panel was added:

- login by admin email/password;
- products list;
- orders list;
- order status update;
- promocode creation;
- CSV product import;
- CSV order export.

Run locally:

```bash
docker compose up --build admin
```

Open:

```text
http://localhost:5174
```

### Product CSV import

Endpoint:

```text
POST /api/admin/products/import-csv
```

Required CSV columns:

```text
sku,title,slug,price,size,variant_sku,stock_qty
```

Optional columns:

```text
brand,description,currency,category,gender,image_url,color,active
```

Sample file:

```text
sample_products_import.csv
```

### Orders CSV export

Endpoint:

```text
GET /api/admin/orders/export-csv
```

Exports:

- order id;
- created date;
- status;
- payment status;
- delivery status;
- amount;
- customer id;
- delivery type;
- address;
- tracking number.

### Preflight

Script:

```bash
python3 scripts/preflight.py --require-env
```

Checks key project files and `.env` keys.

### Tests

Basic tests added:

```bash
pytest backend/tests
```

## Remaining before public launch

Even after v29, do not launch to full traffic until:

1. YooKassa test payment has been verified end-to-end.
2. BotFather domain is configured.
3. Production PostgreSQL backup is configured.
4. Admin password is changed.
5. Real images are uploaded.
6. At least 10 real test orders are processed.
7. Webhook retry/idempotency is tested.
8. Production migration is autogenerated from SQLAlchemy models.
