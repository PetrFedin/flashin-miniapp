# Operator Handover — 1 Day

## Morning

1. Open admin.
2. Check new paid orders.
3. Check fulfillment tasks.
4. Check MoySklad conflicts.
5. Check support tickets.
6. Check SLA overdue.

## During the day

For every paid order:

1. Verify payment status.
2. Open fulfillment task.
3. Pick items.
4. Mark packed/ready.
5. Add tracking if delivery.
6. Notify customer if issue.

## Refund

1. Open order.
2. Check payment status.
3. Check return reason.
4. Approve or reject according to return policy.
5. Verify loyalty points return if used.

## Escalation

| Problem | Escalate |
|---|---|
| Payment mismatch | Finance/backend |
| Missing stock | Inventory |
| App crash | Developer |
| Legal dispute | Legal/management |
| Delivery issue | Operations |
