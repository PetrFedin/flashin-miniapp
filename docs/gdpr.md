
# GDPR Compliance Guide

This document outlines the steps required to ensure that the FLASHIN Mini App complies with the General Data Protection Regulation (GDPR). Key aspects include:

- **Data minimisation**: Only collect data necessary for processing orders and user accounts.
- **Consent**: Obtain explicit consent for marketing communications and optional analytics.
- **Right to be forgotten**: Provide a mechanism for users to request deletion of their personal data.
- **Data portability**: Allow users to export their data in a structured format.
- **Security**: Implement encryption in transit (HTTPS) and at rest for sensitive information.
- **Audit trails**: Maintain logs of consent and data processing activities.

See also `privacy_policy.md` for details on the personal data we collect and how it is used.
