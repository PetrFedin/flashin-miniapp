
# Release History Summary (v1–v22)

This document summarizes highlights from earlier versions of the FLASHIN Mini App:

- **v1–v5**: Implemented core e-commerce flows (catalogue, cart, checkout, payments via mock and live providers), and built a basic Telegram Mini App with a bot integration.
- **v6–v8**: Added roles for admins, CSV import of products, payment webhooks, and initial production hardening including health checks and environment configuration. Added CORS restrictions, JWT auth for admin login, and production `.env`.
- **v9–v11**: Added smoke tests, release/rollback runbooks, post-launch observability and analytics, QA scenarios, and acceptance tests. Enhanced premium UI and event tracking.
- **v12–v15**: Added merchandising guides, payment test plans, operational manuals, refund handling, reservation of inventory, incident reporting, and risk management. Included privacy/offer drafts, SLA/escalation procedures, and prelaunch gating.
- **v16–v22**: Completed technical hardening, secret rotation runbooks, performance budgets, pilot launch plans, final handover documentation (RACI matrix, technical passports, module maps), production migration plans, and final audits.

The current version (v23) builds upon this foundation with internationalisation, GDPR compliance, multi-currency support, and refined documentation.
