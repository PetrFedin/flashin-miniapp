# Support Handover Pack

## What support must know

- How to find an order.
- How to read payment status.
- How to check fulfillment status.
- How to create/close support ticket.
- How to explain refund status.
- How to escalate payment issues.
- How to escalate stock issues.

## Standard escalation

| Issue | Escalate to |
|---|---|
| Payment mismatch | Finance/backend |
| Missing stock | Operations/inventory |
| Refund dispute | Finance/legal |
| Mini App crash | Frontend/backend |
| Bot not responding | Backend/bot |
| Wrong product data | Inventory/MoySklad owner |

## Customer status language

Use clear status, no technical jargon.

Bad:

```text
Webhook not processed.
```

Good:

```text
Платёж подтверждается платёжной системой. Мы проверим заказ и вернёмся с подтверждением.
```
