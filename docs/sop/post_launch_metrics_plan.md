# Post-launch Metrics Plan

## First 24 hours

Track:

- sessions;
- product views;
- add to cart;
- checkout started;
- payment created;
- payment succeeded;
- payment canceled;
- support tickets;
- failed webhooks.

## Commercial metrics

- GMV;
- orders;
- AOV;
- conversion;
- repeat orders;
- refund rate;
- loyalty redemption rate;
- referral activation.

## Operations metrics

- paid to fulfillment task time;
- picking time;
- SLA overdue count;
- MoySklad conflicts;
- stock reconciliation mismatches.

## Alert thresholds

- payment error > 5%;
- webhook failure > 2%;
- checkout error > 3%;
- SLA overdue > 5 orders;
- MoySklad sync failed twice in a row.
